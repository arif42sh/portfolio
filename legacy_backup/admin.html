⚙️ Supabase (PostgreSQL & Storage) Setup

Connect your cloud database in 2 minutes.

Found in your Supabase Dashboard → Settings → API → Project URL
Found in Supabase Dashboard → Settings → API → Project API Keys (anon public)

📋 Easy Step-by-Step Setup Guide:

  1. Go to supabase.com and Sign In with your GitHub account (Free).
  2. Click New Project, give it a name (e.g., portfolio-db) and set a database password.
  3. In the left sidebar, click SQL Editor → click New Query.
  4. Open your project's schema.sql file, copy all the code, paste it into Supabase SQL Editor and click Run.
  5. Go to Project Settings (gear icon) → API → Copy the Project URL and anon public key, paste them above, and click Save & Connect!
